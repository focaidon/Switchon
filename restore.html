스위치온 기존 기록 복원

이전에 Firebase에서 내보낸 tracker_data JSON 파일을 현재 사용 중인 브라우저의 스위치온 기록으로 옮깁니다.

이 페이지는 기존 스위치온과 같은 GitHub Pages 주소에서 열어야 합니다. 평소 사용하던 브라우저에서 실행하세요. 시크릿 창 또는 다른 기기에서는 익명 사용자 ID가 달라질 수 있습니다.

1Firebase 연결 확인

Firebase 로그인 상태를 확인하고 있습니다...

읽기 권한 오류가 나타나면 Firebase Realtime Database의 users/$uid 보안 규칙을 먼저 설정해야 합니다.

2백업 JSON 선택

파일을 선택하면 복구할 기록 수를 확인할 수 있습니다.

3기존 기록 안전하게 복원

기본 설정에서는 현재 기록은 유지하고, 백업에서 누락된 항목만 추가합니다.

복원 실행 전에는 Firebase 데이터가 변경되지 않습니다.

복원 완료 후 원래 스위치온 페이지를 새로고침하세요. 이 파일(restore.html)은 GitHub 저장소에서 삭제해도 됩니다.
